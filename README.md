# 대한사료 양돈 경영분석

양돈농장 수익·비용 구조 분석 웹앱. 기존 엑셀 「양돈농장 수익 비용구조 시뮬레이션」을 웹으로 옮기고, 사료 컨설팅용 기능을 더했습니다.
**바로 사용: https://dhfeed72-gif.github.io/pig-farm-analysis/**

PC·휴대폰 브라우저에서 로그인 없이 쓰고, 휴대폰에서는 「홈 화면에 추가」로 앱처럼 설치할 수 있습니다(오프라인 동작).

## 화면

| 탭 | 내용 |
|---|---|
| ① 기본 입력 | **노란 칸만 입력**(농장명, 시뮬레이션 MSY·돈가, 민감도 범위) → 바로 분석. 회색 칸(모돈수·기준 MSY·돈가·생체중·지육율·FCR·사료단가·두당 비용)은 엑셀 기본값으로 채워져 있고 필요하면 수정 |
| ② 분석 결과 | 종합요약, 전국 기준 대비 진단, 개선 효과 순위, 현재·목표 비교, 두당 생산비 구조, MSY×돈가 민감도, 보고서 인쇄/PDF (월별 실적이 있으면 월별 추이·점검 필요 월 추가) |
| ③ 사료 컨설팅 | 사료 전환 효과 시뮬레이터(단가 인상 vs FCR·MSY 개선), 구간별 사료 사용비율 vs 표준비율 |
| ④ 월별 실적 (선택) | 월별 두수·사료·판매·비용 입력(PC 12개월 표 / 휴대폰 월별), 엑셀 불러오기, 「이 실적으로 기본값 계산 적용」 |

## 데이터

- 입력값은 **사용하는 기기의 브라우저에만 저장**됩니다(서버 없음). 기기를 바꾸거나 브라우저 데이터를 지우면 사라지므로 「백업 저장」(JSON)으로 보관하세요.
- 여러 농장을 등록해 전환할 수 있습니다.

## 계산

`calc.js`는 엑셀 수식을 그대로 옮겼습니다. 원본 엑셀 결과값과의 일치 검증:

```bash
node tools/test.js
```

예시 데이터(`sample.js`)는 엑셀에서 추출합니다:

```bash
python tools/extract_sample.py "양돈농장수익 비용구조_시뮬레이션.xlsx" > sample.js
```
